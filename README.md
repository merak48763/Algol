# Algol

This project contains datapacks that implements some frequently-used features in Minecraft maps (mainly CTM).  
To avoid maps all looking the same, most of the features are utilities rather than cool mechanisms.

Target Minecraft version: 1.21.11 ~ 26.3

> [!IMPORTANT]
> The packs in this repository are maintained primarily for my own use.  
> The features, APIs and supported versions may change at any time without prior notice.
