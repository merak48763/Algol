# Algol - Fancy Woolbox

Dependency: core

## Woolbox Interactions

### Break

- Attack (left click) the interaction entity in creative mode to break the woolbox.

### Set item

- Interact (right click) with the interaction entity while holding item in creative mode to set item inside.
- Item count information will be copied.

### Get item

- Interact (right click) with the interaction entity to get a **copy of** the item stack inside.
- The item can be duplicated infinitely.

## Function API

### `algol.fwb:place_here`

- Execute the function in chat to place a woolbox.
